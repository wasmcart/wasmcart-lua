Asset licensing for this port
=============================

EVERYTHING IN THIS DIRECTORY IS FREELY REDISTRIBUTABLE.
There is no non-commercial or no-derivatives content here.

MIT (generated for this project)
--------------------------------
  sprites/            all 73 images
  maps/tilesheets/    all 4 tilesheets
  maps/*.lua          all 36 level layouts
  music/              6 tracks
  sounds/             24 sound effects

None of these are Cavern's originals. Cavern's own art, audio and level
designs are CC BY-NC-ND 4.0 (attribution, non-commercial, no derivatives),
which cannot be redistributed in a permissively-licensed project. Every
file above is instead generated by:

    ../tools/make-assets.py    sprites + tilesheets
    ../tools/make-audio.py     sound effects + music
    ../tools/make-maps.py      level layouts

Run them to regenerate everything from scratch; output is deterministic.

Each sprite matches the original's exact pixel dimensions, because the game
positions art by width and height. Each map satisfies the layer contract in
source/levels/map_loader.lua (Walls / Transitions / Room / Main_Tiles, plus
optional Pickups / Enemies / Breakables / Water / Vines / Saves).
